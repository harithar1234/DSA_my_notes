Lecture 4 Final Takeaways: Basic Maths

This lecture covers basic maths for DSA: digit extraction, count digits, reverse number, palindrome, divisors, prime numbers, and GCD/HCF. The most important concept is digit extraction, because it is reused in many problems.

1. Extract Digits

To extract the last digit of a number:

int lastDigit = n % 10;

To remove the last digit:

n = n / 10;

Example

n = 7789
7789 % 10 = 9
7789 / 10 = 778

778 % 10 = 8
778 / 10 = 77

77 % 10 = 7
77 / 10 = 7

7 % 10 = 7
7 / 10 = 0

Digits extracted:

9 8 7 7

Code

while (n > 0) {
    int lastDigit = n % 10;
    cout << lastDigit << " ";
    n = n / 10;
}

Time Complexity: O(log10 N), because the number is divided by 10 every time.

2. Count Digits

Example:

n = 7789
digits = 4

Formula

int count = (int)(log10(n) + 1);

Example

log10(7789) = 3.89
3.89 + 1 = 4.89
int(4.89) = 4

Loop Method: O(log10 N)

Formula Method: O(1)

3. Reverse a Number

Example:

n = 7789
reverse = 9877

Formula:

reverseNumber = reverseNumber * 10 + lastDigit;

Dry Run

rev = 0

lastDigit = 9
rev = 0 * 10 + 9 = 9

lastDigit = 8
rev = 9 * 10 + 8 = 98

lastDigit = 7
rev = 98 * 10 + 7 = 987

lastDigit = 7
rev = 987 * 10 + 7 = 9877

Code

int reverseNumber = 0;

while (n > 0) {
    int lastDigit = n % 10;
    reverseNumber = reverseNumber * 10 + lastDigit;
    n = n / 10;
}

cout << reverseNumber;

Time Complexity: O(log10 N)

4. Check Palindrome Number

A number is palindrome if its reverse is equal to the original number.

121  -> palindrome
1331 -> palindrome
123  -> not palindrome

Important: Store the original number before changing n.

Code

int original = n;
int reverseNumber = 0;

while (n > 0) {
    int lastDigit = n % 10;
    reverseNumber = reverseNumber * 10 + lastDigit;
    n = n / 10;
}

if (original == reverseNumber) {
    cout << "true";
} else {
    cout << "false";
}

Time Complexity: O(log10 N)

5. Print All Divisors: Brute Force

Divisors of 36:

1 2 3 4 6 9 12 18 36

Code

for (int i = 1; i <= n; i++) {
    if (n % i == 0) {
        cout << i << " ";
    }
}

Time Complexity: O(N)

6. Print All Divisors: Optimized

Observation:

36 = 1 * 36
36 = 2 * 18
36 = 3 * 12
36 = 4 * 9
36 = 6 * 6

You only need to loop till sqrt(n). Use i * i <= n to avoid repeatedly calling sqrt(n).

Code

vector<int> divisors;

for (int i = 1; i * i <= n; i++) {
    if (n % i == 0) {
        divisors.push_back(i);

        if (n / i != i) {
            divisors.push_back(n / i);
        }
    }
}

sort(divisors.begin(), divisors.end());

for (auto it : divisors) {
    cout << it << " ";
}

For n = 36, output:

1 2 3 4 6 9 12 18 36

Time Complexity: O(sqrt(N)) + O(number_of_factors log number_of_factors)

7. Prime Number

Correct definition:

A prime number has exactly 2 factors: 1 and itself.

Examples:

11 -> prime: 1, 11
13 -> prime: 1, 13
4  -> not prime: 1, 2, 4
1  -> not prime

Brute Force Code

int count = 0;

for (int i = 1; i <= n; i++) {
    if (n % i == 0) {
        count++;
    }
}

if (count == 2) {
    cout << "Prime";
} else {
    cout << "Not Prime";
}

Time Complexity: O(N)

Optimized Code

int count = 0;

for (int i = 1; i * i <= n; i++) {
    if (n % i == 0) {
        count++;

        if (n / i != i) {
            count++;
        }
    }
}

if (count == 2) {
    cout << "Prime";
} else {
    cout << "Not Prime";
}

Time Complexity: O(sqrt(N))

8. GCD / HCF

GCD means Greatest Common Divisor. HCF means Highest Common Factor.

Example

n1 = 9
n2 = 12

Factors of 9  = 1, 3, 9
Factors of 12 = 1, 2, 3, 4, 6, 12

Common factors = 1, 3
GCD = 3

More examples:

GCD(11, 13) = 1
GCD(20, 40) = 20

Brute Force Code

int gcd = 1;

for (int i = 1; i <= min(n1, n2); i++) {
    if (n1 % i == 0 && n2 % i == 0) {
        gcd = i;
    }
}

cout << gcd;

Time Complexity: O(min(n1, n2))

Better Brute Force From Back Side

for (int i = min(n1, n2); i >= 1; i--) {
    if (n1 % i == 0 && n2 % i == 0) {
        cout << i;
        break;
    }
}

Worst-case time complexity is still O(min(n1, n2)).

9. Euclidean Algorithm for GCD

Main formula:

gcd(a, b) = gcd(a % b, b)

Keep reducing until one number becomes 0.

Example

gcd(52, 10)

52 % 10 = 2
gcd(2, 10)

10 % 2 = 0
gcd(2, 0)

Answer = 2

Code

while (a > 0 && b > 0) {
    if (a > b) {
        a = a % b;
    } else {
        b = b % a;
    }
}

if (a == 0) {
    cout << b;
} else {
    cout << a;
}

Time Complexity: O(log(min(a, b)))
