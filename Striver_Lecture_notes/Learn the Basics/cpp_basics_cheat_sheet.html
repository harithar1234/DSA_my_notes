7. Switch

switch (day)
{
case 1:
    cout << "Monday";
    break;

case 2:
    cout << "Tuesday";
    break;

default:
    cout << "Invalid";
}

Input:

2

Output:

Tuesday

Final Notes

Always remember break;. Otherwise execution continues into the next case, which is called fall-through.

Difference Between If-Else and Switch-Case

In C++, if-else evaluates complex conditional expressions such as ranges, logical operations, and different variables. switch-case maps a single integral expression to specific constant values.

Key Differences

FeatureIf-Else LadderSwitch-Case Statement
Expression TypeEvaluates any expression returning a boolean value: true or false.Evaluates only integral types such as int, char, and enum.
ConditionsHandles ranges, logical operators like && and ||, and multiple variables.Handles exact constant values only.
Execution FlowEvaluates conditions sequentially until it finds a true match.Jumps directly to the matching case when optimized by the compiler.
Fall-ThroughDoes not support fall-through. Only one matching block executes.Supports fall-through unless stopped with a break statement.
Default FallbackHandled by the optional trailing else block.Handled explicitly by the default: label.

Underlying Performance Mechanics

Sequential Testing: An if-else chain makes the CPU evaluate conditions one after another. If the matching condition is at the bottom of 20 conditions, it may execute 19 failed checks first.

Jump Tables: For many contiguous values, the compiler can optimize a switch statement into a jump table or lookup array. This can let the CPU compute the address of the matching case and jump directly to it in constant time.

When to Use If-Else: Ranges and Complex Logic

// Best for complex conditions, floating-point numbers, or multiple variables
if (score >= 90 && score <= 100) {
    std::cout << "Grade: A";
} else if (score >= 80) {
    std::cout << "Grade: B";
} else {
    std::cout << "Retake required";
}

When to Use Switch-Case: Fixed Values and Cleaner Semantics

// Best for fixed options like menu items, keyboard inputs, or enums
switch (menuSelection) {
case 1:
    startNewGame();
    break; // Prevents execution from falling into case 2

case 2:
    loadSavedGame();
    break;

default:
    std::cout << "Invalid selection";
    break;
}

8. Arrays

Declaration

int arr[5];

Input

cin >> arr[0];
cin >> arr[1];
cin >> arr[2];
cin >> arr[3];
cin >> arr[4];

Input:

3 4 5 7 9

Memory:

Index: 0 1 2 3 4
Value: 3 4 5 7 9

Access

cout << arr[3];

Output:

7

Modify

arr[3] = 16;

Output:

16

Final Notes

  • Arrays use 0-based indexing.
  • Elements are stored in contiguous memory.
  • All elements must be of the same datatype.

11. For Loop

for (int i = 1; i <= 5; i++)
{
    cout << i << " ";
}

Output:

1 2 3 4 5

Reverse

for (int i = 5; i >= 1; i--)

Output:

5 4 3 2 1

Final Notes

Structure:

for (initialization; condition; update)

This loop is the backbone of most DSA algorithms.

12. While Loop

int i = 1;

while (i <= 5)
{
    cout << i;
    i++;
}

Output:

12345

Final Notes

Use when the number of iterations is not known beforehand.

13. Do While

int i = 10;

do
{
    cout << i;
    i++;
}
while (i <= 5);

Output:

10

Final Notes

do-while always executes at least once, even if the condition is initially false.

Functions are used to reuse code, improve readability, modularize programs, and avoid repeating logic.
