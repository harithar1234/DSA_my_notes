Lecture 2: Time Complexity and Space Complexity

This is a concise interview cheat sheet for Lecture 2 of Striver's A2Z DSA Course. It covers the final concepts, formulas, examples, and code needed before solving DSA problems.

1. What is Time Complexity?

Time complexity is not the actual execution time.

The same code can take different times on different machines.

MachineTime Taken
Old Windows PC2 sec
New MacBook1 sec

Time Complexity = rate at which execution time grows with input size N, not actual seconds.

2. Big-O Notation

Time complexity is represented as:

O(...)

Examples:

O(1)
O(log N)
O(N)
O(N log N)
O(N^2)

Interviewers expect the answer in Big-O notation, not in seconds.

3. How to Compute Time Complexity?

Single Loop

for (int i = 1; i <= N; i++)
{
    cout << "Hello";
}

This loop runs N times.

Time Complexity = O(N)

Nested Loop

for (int i = 0; i < N; i++)
{
    for (int j = 0; j < N; j++)
    {
        cout << "Hello";
    }
}

Outer loop runs N times and inner loop runs N times.

Total = N x N
Time Complexity = O(N^2)

4. Three Rules to Compute Time Complexity

Rule 1: Always Compute Worst Case

Worst Case

Do not focus only on best case. The system should work for the largest possible input.

Rule 2: Ignore Constants

O(3N)  -> O(N)
O(10N) -> O(N)

Constants do not matter for very large values of N.

Rule 3: Ignore Lower Order Terms

O(N^2 + N + 100) -> O(N^2)

For large inputs, N^2 dominates N and constants.

5. Best, Average, Worst Case

if (marks < 25)
    Grade D;
else if (marks < 45)
    Grade C;
else if (marks < 65)
    Grade B;
else
    Grade A;

Best Case

Input:

marks = 10

Only the first condition executes.

O(1)

Worst Case

Input:

marks = 70

Every condition is checked, but the number of checks is still constant.

O(1)

Interviewers usually ask for the worst-case complexity.

6. Example 1: Square Nested Loop

for (int i = 0; i < N; i++)
{
    for (int j = 0; j < N; j++)
    {
        // constant work
    }
}
Iterations = N x N
Answer = O(N^2)

7. Example 2: Triangular Nested Loop

for (int i = 0; i < N; i++)
{
    for (int j = 0; j <= i; j++)
    {
        // work
    }
}

Iterations:

1
2
3
...
N

Total:

1 + 2 + 3 + ... + N

Formula:

N(N + 1) / 2

Exact complexity:

O((N^2 + N) / 2)

After applying the rules:

O(N^2)

9. Space Complexity

Space complexity is calculated as:

Space Complexity = Auxiliary Space + Input Space
TermMeaning
Auxiliary SpaceExtra memory used by the algorithm.
Input SpaceMemory required to store the input.

10. Space Complexity Example

int a, b;
int c = a + b;

Memory used:

a
b
c
TypeVariables
Input Spacea, b
Auxiliary Spacec
 
Total Space = O(3) -> O(1)

This simplifies to O(1) because it is constant space.

11. Arrays and Space

int arr[N];

An array of size N is allocated.

Space Complexity = O(N)

12. Interview Tip: Avoid Modifying Input

Instead of modifying input directly:

b = a + b;

Prefer storing the result in a new variable:

int c = a + b;

Reason:

  • Original input should remain unchanged.
  • Other parts of the program may rely on it.
  • Modifying inputs is poor practice unless explicitly allowed.

13. Competitive Programming Rule

A common approximation is:

10^8 operations ~= 1 second
Time LimitMaximum Operations Approx.
1 sec10^8
2 sec2 x 10^8
5 sec5 x 10^8

This helps estimate whether an algorithm will fit within the time limit.
