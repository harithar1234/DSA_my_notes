Lecture 5 Final Takeaways: Recursion Basics

This lecture introduces recursion theory: what recursion is, why infinite recursion causes stack overflow, what a base condition is, and how recursion calls are represented using a recursion tree.

1. What Is Recursion?

Recursion means:

When a function calls itself.

Example idea:

void f() {
    f();
}

Here, function f() is calling itself again and again.

2. Infinite Recursion

If a recursive function has no stopping condition, it keeps calling itself forever.

void print() {
    cout << 1 << endl;
    print();
}

int main() {
    print();
    return 0;
}

Output:

1
1
1
1
1
...

Final Point: If recursion has no stopping condition, it becomes infinite recursion.

3. Stack Overflow

Every function call waits in memory until it finishes. In recursion, if a function keeps calling itself, many unfinished function calls keep piling up in stack memory.

Example flow:

main() calls print()
print() calls print()
print() calls print()
print() calls print()
...

Since none of these calls finish, stack memory fills up.

Final Point: Too many pending recursive calls cause stack overflow.

In C++, this often appears as Segmentation fault.

4. Base Condition

A base condition is the stopping condition of recursion.

Without Base Condition

void f() {
    cout << 1 << endl;
    f();
}

With Base Condition

int cnt = 0;

void f() {
    if (cnt == 3) {
        return;
    }

    cout << cnt << endl;
    cnt++;
    f();
}

Main function:

int main() {
    f();
    return 0;
}

Output:

0
1
2

Dry run:

cnt = 0 -> print 0 -> cnt becomes 1
cnt = 1 -> print 1 -> cnt becomes 2
cnt = 2 -> print 2 -> cnt becomes 3
cnt = 3 -> base condition true -> return

Final Point: Base condition stops recursion and prevents stack overflow.

5. What Does return Do?

Inside a function, return immediately stops that function.

if (cnt == 3) {
    return;
}

When cnt == 3, the function stops and does not execute the lines below:

cout << cnt << endl;
cnt++;
f();

6. Recursion Call Flow

For this code:

int cnt = 0;

void f() {
    if (cnt == 3) {
        return;
    }

    cout << cnt << endl;
    cnt++;
    f();
}

Call flow:

f() -> cnt = 0 -> print 0 -> call f()
f() -> cnt = 1 -> print 1 -> call f()
f() -> cnt = 2 -> print 2 -> call f()
f() -> cnt = 3 -> return

Then control goes back:

return to previous f()
return to previous f()
return to previous f()
return to main()

7. Recursion Tree

A recursion tree is a simple diagram showing recursive function calls.

For the above function:

f()
 |
 f()
 |
 f()
 |
 f()
 |
return

Meaning:

First f() calls another f()
That f() calls another f()
That f() calls another f()
Then base condition is met and recursion stops

Most Important Recursion Structure

void f() {
    if (base_condition) {
        return;
    }

    // work

    f();
}

Final Statement: Every recursive function must have a base condition. Without a base condition, recursion becomes infinite and causes stack overflow.
